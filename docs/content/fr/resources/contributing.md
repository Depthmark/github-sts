Les contributions sont les bienvenues. Les directives de contribution officielles se trouvent dans le fichier [`CONTRIBUTING.md`](https://github.com/Depthmark/github-sts/blob/main/CONTRIBUTING.md) du dépôt.

Pour travailler localement sur ce site de documentation :

```bash
# Servez le site de documentation localement
task docs:serve
# ou
make docs-serve

# Construisez le site de production
task docs:build
# ou
make docs-build
```

Le site est disponible à :
- Anglais : `http://localhost:1313/github-sts/`
- Français : `http://localhost:1313/github-sts/fr/`
