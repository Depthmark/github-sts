Contributions are welcome. The canonical contribution guidelines live in the repository's [`CONTRIBUTING.md`](https://github.com/Depthmark/github-sts/blob/main/CONTRIBUTING.md).

To work on this documentation site locally:

```bash
# Serve the documentation site locally
task docs:serve
# or
make docs-serve

# Build the production site
task docs:build
# or
make docs-build
```

The site is available at:
- English: `http://localhost:1313/github-sts/`
- French: `http://localhost:1313/github-sts/fr/`
